📄 Ce este HTML?

HTML (HyperText Markup Language) este limbajul de bază folosit pentru a crea pagini web.

📌 Elementele HTML

HTML este format din etichete (tags), care indică browserului cum să afișeze conținutul. Fiecare etichetă are o formă generală:

<nume_eticheta>Conținut</nume_eticheta>

Exemplu:

<p>Acesta este un paragraf.</p>

🔹 Etichete de bază

  • <h1> - <h6> | Titluri (de la cel mai mare la cel mai mic)
  • <p> | Paragraf
  • <br> | Linie nouă (fără etichetă de închidere)
  • <a> | Link (ancoră)
  • <img> | Imagine
  • <ul> , <ol> , <li> | Liste

📖 Exemplu complet

<!DOCTYPE html> <html> <head> <title>Exemplu HTML</title> </head> <body> <h1>Salut!</h1> <p>Aceasta este prima mea pagină web.</p> </body> </html>
