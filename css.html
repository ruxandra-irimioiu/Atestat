🎨 Ce este CSS?

CSS (Cascading Style Sheets) este un limbaj folosit pentru a stiliza paginile web scrise în HTML.

📌 De ce avem nevoie de CSS?

HTML descrie structura unei pagini, dar nu și cum arată. CSS ne ajută să schimbăm:

  • Culorile textului și fundalului
  • Fonturile și dimensiunile
  • Marginile și alinierea
  • Aspectul general al site-ului

🔧 Sintaxa de bază

Exemplu de regulă CSS:

selector { proprietate: valoare; }

Exemplu concret:

h1 { color: blue; text-align: center; }

🧪 3 moduri de a folosi CSS

  • CSS inline – <p style="color:red;">Text roșu</p>
  • CSS intern – în interiorul paginii, între <style> și </style>
  • CSS extern – într-un fișier separat, conectat cu <link>
