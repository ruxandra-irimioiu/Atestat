💻 Exemplu Practic

Mai jos este un exemplu simplu de pagină HTML care include un titlu, un paragraf, o imagine și un link:

🔧 Codul:

<!DOCTYPE html> <html> <head> <title>Pagina mea</title> </head> <body> <h1 id="titluExemplu">Bun venit!</h1> <p>Aceasta este prima mea pagină web.</p> <img src="https://bit.ly/120px-HTML5_logo_and_wordmark.svg.png" alt="Logo HTML5"> <p>Înapoi la <a href="index.html">pagina principală</a>.</p> </body> </html>

🧪 Experimentează:
